# 현장 손상 표기 앱

외관조사망도 PDF 위에 S펜으로 손상을 표기하고, CAD용 DXF·손상목록 CSV·사진을 zip으로 내보내는 설치형 웹앱(PWA)입니다.
한 번 설치하면 인터넷 없이 현장에서 작동하고, 표기 데이터는 태블릿 안에만 저장됩니다(서버로 올라가지 않음).

## 배포 (GitHub Pages)

1. 이 폴더의 파일을 GitHub 저장소 최상위에 올립니다 (`index.html`, `sw.js`, `manifest.webmanifest`, `icons/`, `vendor/`).
2. 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 저장합니다.
3. 1~2분 뒤 `https://<계정명>.github.io/<저장소명>/` 주소가 생깁니다.

## 갤럭시탭에 설치

1. 갤럭시탭 **크롬**에서 위 주소를 엽니다.
2. 상단의 **앱 설치** 버튼을 누르거나, 크롬 메뉴(⋮) → **앱 설치(홈 화면에 추가)**를 누릅니다.
3. 홈 화면의 "손상표기" 아이콘으로 실행합니다. 한 번 실행한 뒤에는 오프라인에서도 열립니다.

## 수정 후 배포

파일을 고쳐 올릴 때는 `sw.js`의 `VERSION` 값을 올립니다(`v1` → `v2`). 태블릿은 인터넷이 연결된 상태에서 앱을 열 때 새 버전을 받고, 다음 실행부터 적용됩니다.

## 주의

- 표기 데이터는 그 태블릿의 앱 저장소에 있습니다. 크롬의 "사이트 데이터 삭제"나 앱 삭제를 하면 지워지므로, 현장 작업 후에는 **내보내기**로 zip을 받아 두세요.
- 내보낸 zip은 다른 기기에서 **백업 불러오기**로 이어서 작업할 수 있습니다.
- 저장소가 공개(Public)여도 올라가는 것은 앱 코드뿐이고, 도면 PDF와 표기 내용은 올라가지 않습니다.
